# Admin Dashboard

This is an implementation for the front-end side of admin dashboard built based on given design. I have build this practice project as part of [The Odin Project](https://www.theodinproject.com/dashboard) curriculum

[Github Repo](https://github.com/mohamedmostafakhudari/admin-dashboard-TOP)
[Preview Link](https://mohamedmostafakhudari.github.io/admin-dashboard-TOP/)

## Featuring
- Design to Code
- Vanilla HTML and CSS
- Grid and Flexbox Layout modes
- Usage of modern styling approaches (i.e. @scope - @container)
- Embrace the component-based approach of development and reusability
## Known issues
- performance bottlenecks because of @import statements
  - reason: separate consecutive network requests to fetch each component stylesheet file
  - possible solution: preprocessors like SCSS or bundlers like postcss / vite / webpack
